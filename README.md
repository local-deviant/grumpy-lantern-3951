> I told Dad I'm afraid of the dark. He said, 'Good — the dark's afraid of the electricity bill.'

## How it works

`main.py` writes the one-liner to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`), byte-identical with no trailing newline.

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
cat output/entry.txt
```
